## 🚀 Featured Projects

### 🏛️ [University SSO Portal](https://github.com/udaaraSH23)
Monorepo-based multi-portal university system with centralized SSO authentication. Built with Next.js, Turborepo, Prisma, PostgreSQL — orchestrated with Kubernetes, Terraform, and Ansible using a GitOps workflow.

### 🏔️ [Kandy Trekking Tours](https://github.com/udaaraSH23)
Commercial trekking platform with immersive route discovery, SEO optimization, and Resend-powered email inquiries. Built with Next.js + TypeScript, deployed to Vercel.

### 🛒 [Lover Shop E-Commerce](https://github.com/udaaraSH23)
Full-stack e-commerce platform with product management, payments, and an admin panel. React · Spring Boot · MongoDB · Docker Compose.

### ⚡ [Uber-like Microservices (Kafka)](https://github.com/udaaraSH23)
Event-driven microservices system using Apache Kafka for asynchronous service communication. Demonstrates distributed systems design with Node.js + Docker.

### ☁️ [Multi-Cloud Terraform Infrastructure](https://github.com/udaaraSH23)
Hybrid cloud infrastructure provisioned across AWS and GCP using modular Terraform — EC2, S3, DynamoDB on AWS + Compute Engine and Firestore on GCP.

### 🤖 [AI Weightlifting Posture Analysis](https://github.com/udaaraSH23)
End-to-end computer vision and sequence modeling pipeline for Olympic lift analysis. Python · MediaPipe · TensorFlow · GRU · OpenCV — generates corrective biomechanical feedback.
